# Standard 用户引导

本目录是当前唯一默认用户引导；先读 [快速启动](00_quick_start.md)。只有必需事实缺失、主体关系或政策冲突会改变结论时，才读 [集中确认提示](01_evidence_confirmation.md)。

用户流程固定为：一次提交资料 → 按业务核心度动态推荐四类词 → 用户一次选词＋画像范围 → 生成品牌或指定业务画像（默认九项每项800–1000字）。推荐数量不设固定上限；仅必要事实缺失时集中追问；不得逐词或逐画像重复确认，不能跳过选词直接出画像。

唯一交付模板见 `templates/delivery.md`；关键词规则见 `references/keyword-rules.md`；画像规则见 `references/template-guide.md`；下一步文章训练见 `references/article-training.md`。词表只有推荐词与短词根两列，搜索角色卡只作内部依据。Legacy 文件不作为 Standard 规则来源。
