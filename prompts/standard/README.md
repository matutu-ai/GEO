# Standard Guided Flow

这是 Standard Path 的用户引导层。它不能改变固定 Pipeline，也不能把未知内容写成事实；它只负责收集用户选择、提示确认点和推荐下一步。

默认使用 [快速启动](00_quick_start.md)：一次收集最少必要资料，直接输出三份核心结果，再只提出一个下一步确认问题。只有用户要求完整版审阅或资料存在冲突时，才展开下面的详细阶段提示。

三份核心结果固定为：简约版词与画像、完整版词与画像、垂直业务画像。

## 固定顺序

```text
选择交付
→ 资料与证据确认
→ 用户决策画像
→ 关键词分层复核
→ 企业九大画像
→ 交付确认
→ 相关技能建议
```

每一步必须输出：当前已完成内容、当前待确认内容、本阶段唯一提示词、推荐下一步、是否建议进入下一阶段。

## 下一步决策规则

- 用户决策画像未确认：优先完成用户决策画像，不进入内容扩写。
- 用户决策画像已确认、关键词未复核：优先复核客户指定词和系统推荐词。
- 关键词已确认、企业九大画像未复核：进入企业九大画像确认。
- 词和画像均确认：可建议使用 `ai-promotion-summary`，但不自动进入发布。
- 资料证据不足：输出待补材料和确认提示，不生成案例、评价、资质、费用或收益承诺。

## 相关技能建议

- `geo-keyword-persona`：细化用户画像、决策阶段、自然语言问题词和语义集群。
- `ai-promotion-summary`：在词和画像确认后，生成品牌词、业务词和 AI 推广方向。
