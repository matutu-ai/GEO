# 阶段 3：关键词分层复核

## 提示词

```text
请审阅输出的四类关键词，并分别标记：

1. 品牌词：保留、修改、删除或待确认。
2. 搜索词：保留、修改、删除或待确认。
3. 问答词：保留、修改、删除或待确认。
4. 意图场景词：保留、修改、删除或待确认。

另外请标记：

- 客户指定词
- 系统推荐词
- 必须保留的词
- 禁止使用的词

系统推荐词仅作参考，不自动视为已批准。
```

## 完成后的建议

- 客户指定词与事实冲突：保留为待确认，不直接发布。
- 词过多或高度相似：先合并词，再进入企业九大画像。
- 词已经确认：进入用户决策画像确认；用户画像也确认后，再进入企业九大画像。
