# Standard Path 快速启动

默认只给客户这一段，不先展示完整流程：

```text
请直接提供以下 5 项：

1. 企业/品牌名称
2. 主要产品或服务
3. 最想吸引的 1—3 类客户
4. 最想做的 3—10 个词（没有可留空）
5. 本次目标：品牌识别、业务获客、招商代理、用户教育或转化

系统会直接整理出：四类关键词、用户决策画像、企业九大画像状态和 P0/P1/P2 建议。
导出后先只确认一件事：四类关键词中哪些保留、修改、删除或待确认，以及系统推荐词是否加入正式词库。
```

## 快速模式规则

- 不要求客户先填写完整长表。
- 系统先根据已确认资料生成一版结果。
- 第一轮只引导确认四类关键词，不同时要求用户填写长表。
- 关键词确认后，再引导确认用户决策画像和企业九大画像。
- 每轮只保留一个下一步确认问题。
- 详细证据、阶段提示和技能建议放在附加导出，不打断主结果。
- 资料不足时只标记待确认，不自动补写事实。
