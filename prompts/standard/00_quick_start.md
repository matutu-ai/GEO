# GEO 关键词与画像快速启动

默认只给用户这一段，不先展示内部流程：

```text
请一次提供以下信息；已有资料可直接粘贴，未知项写“未知”或留空：

1. 企业/品牌名称
2. 主要产品或服务、企业定位
3. 目标客户与主要使用/采购场景
4. 想做的关键词（可选；没有可留空）
5. 本次目标：品牌认知、业务获客、招商合作、用户教育或转化
6. 画像版本，选一项：
   - 简约版：四类关键词 + 九大画像，每项只写核心事实
   - 完整版：四类关键词 + 九大画像，每个画像段落约 800–1000 个中文字
   - 垂直完整版：指定一个垂直业务，按四类关键词 + 九大画像完整展开；画像段落约 800–1000 个中文字

系统直接生成一份《GEO训练与运营词画像》：品牌词、搜索词、问答词、意图场景词说明推荐词及训练用途；九大画像说明主体事实和运营价值；结尾只给一条最适合的下一步建议。
```

## 交互规则

- 不逐阶段、逐词或逐画像让用户确认；程序按固定合同自动校验，不把校验拆成用户多轮确认。
- 必需事实都清楚时直接生成，不再重复核验已提供资料。
- 只有关键事实缺失或冲突会改变主体、业务、政策或对外表述时，才一次合并所有必要问题；其他缺项标记“待补”。
- 四类关键词固定为品牌词、搜索词、问答词、意图场景词；具体框架见 `references/keyword-rules.md`。
- 九大画像固定为产品或服务描述、产品或服务特点、品牌故事、用户痛点、信任背书、客户案例、社会贡献、客户评价、创始人介绍。
- 完整版目标长度是每个画像段落 800–1000 个中文字，不是整份总字数或英文单词数。证据不足时明确标注资料缺口，不凑字数、不编造。
- 垂直完整版必须聚焦用户指定的单一业务，不混入企业其他业务。
- 仅交付一份结果；不要附加审计文件、重复检查报告或冗长流程说明。

## 程序边界

Standard CLI 当前生成的是精简九大画像表。用户选择完整版或垂直完整版时，Skill 按已确认原始资料与校验结果组织长文；不得把 CLI 精简表称为已满足 800–1000 字要求的完整版。
