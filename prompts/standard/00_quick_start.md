# Standard Path 快速启动

默认只给客户这一段，不先展示完整流程：

```text
请直接提供以下 5 项：

1. 企业/品牌名称
2. 主要产品或服务
3. 最想吸引的 1—3 类客户
4. 最想做的 3—10 个词（没有可留空）
5. 本次目标：品牌识别、业务获客、招商代理、用户教育或转化

系统会直接生成一份《GEO训练与运营词画像》：列出四类推荐词及训练用途、九大画像及运营价值，并给出下一步运营方向。
已确认内容直接进入建议稿；未确认词和缺失资料保留状态提示，不阻塞导出。
```

## 快速模式规则

- 不要求客户先填写完整长表。
- 系统先根据已确认资料生成一版结果。
- 不要求客户先逐词勾选或填写长表。
- 只有未确认信息会影响主体、政策或对外事实准确性时，才追问确认。
- 详细证据和阶段提示在运行时保留校验，默认不生成附加文件。
- 资料不足时只标记待确认，不自动补写事实。
