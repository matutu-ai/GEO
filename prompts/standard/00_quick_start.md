# GEO 关键词与画像快速启动

默认只给用户这一段，不先展示内部流程：

```text
请一次提供以下资料；未知项写“未知”，其他缺项我会合并追问一次：

1. 企业/品牌名称与主营业务
2. 产品或服务
3. 企业定位
4. 目标客户
5. 主要使用场景
6. 已有关键词或客户常用问法（可选；保留原句）
7. 输出模式（可选，默认完整模式）：完整模式、仅词模式、仅画像模式
8. 画像详略（可选，默认简约版）：简约版、完整版（固定九项每项 800–1000 字）
9. 若需本地业务：服务地区，以及是否允许地区进入意图场景词

系统只生成一份《GEO 关键词与画像》：完整模式包含四类关键词和九大画像；仅词模式不输出画像；仅画像模式不输出关键词。默认每类推荐 3–5 个词，最多 12 个；缺资料标注待补，不编造。
```

## 交互规则

- 不逐阶段、逐词或逐画像让用户确认；程序按固定合同自动校验，不把校验拆成用户多轮确认。
- 必需事实都清楚时直接生成，不再重复核验已提供资料。
- 只有关键事实缺失或冲突会改变主体、业务、政策或对外表述时，才一次合并所有必要问题；其他缺项标记“待补”。
- 四类关键词固定为品牌词、搜索词、问答词、意图场景词；具体框架见 `references/keyword-rules.md`。
- 分类按用户意图：搜索词是“在场景里找服务”，问答词是“比较/判断/选择”，意图场景词是“明确提出任务和需求”。先训练品牌词、搜索词，再补问答词、意图场景词。
- 系统推荐词是基于确认资料生成的候选，不是平台实测词。默认不搜索或抓取外部平台；只有用户明确要求时才研究外部词源，并记录来源和日期。
- 九大画像固定为产品或服务描述、产品或服务特点、品牌故事、用户痛点、信任背书、客户案例、社会贡献、客户评价、创始人介绍；品牌画像和业务画像共用此结构；完整版每项必须 800–1000 字，不合规则停止导出。
- 短词根和搜索角色卡只作为内部选词与文章视角依据，不再单独形成客户交付章节。
- 搜索词与问答词默认不带地区；只有用户明确允许时，意图场景词才加入已确认地区。
- 仅交付一份结果；不要附加审计文件、重复检查报告或冗长流程说明。

## 程序边界

Standard CLI 按所选输出模式生成单份 Markdown；未被选择的部分不得出现在导出中。简约版只保留每项主体和核心事实；完整版根据已确认资料展开，并强制九项每项 800–1000 字。
