# Step 2/13 企业 GEO 信息缺口检测

先遵循 `prompts/_interaction_contract.md`。

## 检查清单

### 企业身份

- [ ] 企业名称明确
- [ ] 行业明确
- [ ] 服务区域明确
- [ ] 官网或官方主体链接明确

### 产品资产

- [ ] 产品或服务分类
- [ ] 目标客户
- [ ] 解决问题
- [ ] 技术或能力说明
- [ ] 使用场景
- [ ] 交付方式与限制边界

### 信任资产

- [ ] 企业资质
- [ ] 客户案例及证明材料
- [ ] 客户评价授权材料
- [ ] 新闻或媒体报道
- [ ] 团队或专家公开资料

## 输出

输出 `GEO 基础资料完整度 XX/100`，同时列出：

1. 当前最大问题；
2. 每个缺口对 AI 理解、信任或推荐判断的影响；
3. 优先补充 A / B / C；
4. 无法确认的项目使用 `【需企业提供真实佐证】`。

不要输出虚构的资质缺失结论，例如“缺少人防资质”，除非用户资料或来源明确提到该资质属于当前业务要求。
