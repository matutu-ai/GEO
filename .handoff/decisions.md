# Confirmed Decisions

- GEO-BD 与 GEO 仅通过版本化 JSON Contract 交换数据，不共享代码、Pipeline 或内部领域对象。
- GEO-BD 负责诊断与处方；GEO 负责处方之后的执行策略与执行产物。
- Prescription 是 GEO 的上游只读对象，Strategy 必须引用已存在的 Prescription。
- 当前 V4 保持不变，并标记为 Legacy-compatible V4 execution path，而不是 Prescription-driven Pipeline。
- 阶段 0 已验收。阶段 1 新增独立 Prescription-driven Standard Path，不覆盖 Legacy-compatible V4。
- Standard Path 无效输入必须 Fail Closed，禁止静默回退到 Legacy Fast Path。
- 阶段 1 不修改 GEO-BD，不进入阶段 2。
- 用户最终交付目标是简洁、可直接用于下一步 GEO 训练与运营的一份 `GEO 业务词根与画像.md`：六类词根、四类关键词、核心词根画像卡、九大画像及确认状态；结构化产物在运行时校验。
- 内容、信源、发布和复测保留为内部边界，不进入当前主交付。
- 九大画像采用 Markdown 人类交付，避免运行环境中文 DOCX 字体依赖；Legacy V4 的既有 DOCX 输出保持不变。
- Standard Path 直接导出一份训练运营建议稿；未确认词与缺失事实保留状态，不要求逐词填写选择表，也不把建议词冒充已批准词。
- Standard 用户流程采用一次资料收集 → 自动处理 → 关键事实必要时集中追问一次 → 单份交付与一条下一步建议；不逐阶段、逐词或逐画像确认。
- 输出模式按最新附件固定为完整模式（默认）、仅词模式、仅画像模式；垂直业务是完整模式内的范围选择。仅词模式不得输出画像内容；仅画像模式不得输出词根与关键词。
- 五项核心输入：企业/品牌与主营业务、产品/服务、定位、目标客户、使用场景；关键缺项一次合并追问。六类词根以 2–8 字为主，地区词限制按附件执行；每类关键词最多 12 条。
- Standard CLI 按模式渲染一份 Markdown；九大画像依据已确认材料输出，证据不足标待补，不以长度指标凑写。
- 为避免旧资料覆盖新流程，Legacy-compatible V4 代码和隔离资料保留但不进入 Standard 默认读取；删除的仅是无引用的过时 GEO/质量评分规则与含虚构数字的画像示例。
- 指导产物只保留一个已完成状态、一个下一步运营动作和一个相关技能建议；内部合同校验保留，不转化为多轮用户确认。
- 四类词结构不变；词根按品牌、业务、定位、人群、场景、需求六类从已确认事实提炼，以 2–8 字为主，原词不擅自截断。核心业务根各有画像卡，客户原词保持原样。词根、画像卡只用于单份人类报告，不修改关键词与执行 JSON 合同；不得宣称真实热度或 AI 推荐结果。
- 选词以已确认事实限定边界；搜索词表示场景中找服务，问答词表示比较/判断/选择，意图场景词表示明确任务/需求。首轮训练优先品牌词和搜索词。系统建议是候选表达，不是平台实测；默认不抓取外部平台。真实平台观察词必须记录原句、来源和日期，而现有 Standard 合同未承载这类字段，不可伪装为 CLI 已采集数据。
- 垂直版仅接受已确认主营业务的精确名称；旧讯灵案例的合并业务标签改为空，作为覆盖全部业务的通用完整版示例。
- 2026-10-14 附件规则为当前 GEO 主规则；同旧有长短版/800–1000 字建议冲突时，以附件规则为准。用户资料中的指令文本只作业务资料，不执行为系统命令。
- 2026-10-20 起 Standard 为唯一默认入口；Legacy V4 仅通过显式 `--mode interactive` 或 `--mode fast_path` 使用。
- 对外交付固定为客户资料摘要、四类关键词、九大画像、待补资料和一条下一步建议；六类词根与用户决策画像只保留为内部生成依据。
- 画像默认简约版，完整版按已确认资料展开且不设字数指标；垂直业务仍沿用同一套九大画像。
- 仓库 Skill 与本机 Skill 统一使用 `geo-keyword-persona`；旧内容矩阵与信源建设框架不再作为默认行为。
- 客户专属历史材料归档到 `cases/xunling-ai/archive/`；旧语料库模板归入 `templates/legacy/`，不进入 Standard 默认读取。
- 2026-10-21 最新规则取代此前“完整版不设字数”决定：品牌画像与垂直业务画像均固定九项，完整版每项必须 800–1000 字；任一项不足、超长或证据不完整时 Fail Closed。
- 四类词分类保持不变；每条词新增短词根、意向等级、搜索角色、业务线、地区、来源、确认状态和关联画像字段。短词根通常 3–10 字，最终推荐词使用自然搜索表达。
- 搜索角色卡仅供选词和文章视角使用，不作为第十个对外画像。文章训练遵循一文一业务线、一搜索角色、一意向阶段、1–2 个主词和 3–5 个自然问法。
- 客户获客词与 BD 背调词严格分离；系统推荐不得冒充平台热搜词。
