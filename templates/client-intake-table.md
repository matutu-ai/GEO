# 客户资料填写表模板

用途：AI 分析完 GEO V3 仓库框架后，向用户询问是否需要表格；用户确认需要时，把本模板输出为 Markdown 表格供客户逐项填写。

## 使用规则

1. 一次输出一张主表；多个核心产品时，产品区按每个产品各填一行。
2. 客户不知道的内容填“待补充”，不能公开的内容填“不公开”，不能为空后由 AI 编造。
3. 客户直接给 docx、xlsx、pdf、图片、网页链接时，可不用逐格填写，由 AI 提取后按同一框架核对缺项。
4. AI 收到的每条内容按证据等级处理：客户原文为 FACT，未验证公开信息为 VERIFIABLE，无法核验标 MISSING。
5. 本表只负责收集原始资料，不改变九大板块、schema 和后续简约版/完整版/垂直画像流程。

## 推荐主表

| 区块 | 客户需要填写的内容 |
| --- | --- |
| 企业主体 | 公司全称、品牌/常用简称、所属行业与细分行业、成立时间、注册地、实际经营地、法定代表人、官网、公众号/视频号等官方账号、主营业务、主要客户类型与经营地区 |
| 产品与服务 | 每个核心业务分别填写：产品/服务名称和版本、品类与形态、目标客户、核心功能、参数/规格/服务档位、交付周期、适用场景、解决什么痛点、客户获得什么结果、配套服务和售后、明确不支持项、报价是否公开 |
| 信任证据 | 资质证书名称与编号、专利/软著名称与编号、算法备案、合作方与协议范围、第三方报道、客户规模依据、厂房/团队/服务能力、每条证据的链接或文件 |
| 案例与评价 | 客户行业与背景、项目诉求、原有痛点、落地方案、量化结果、效果数据口径、客户评价原文与来源、是否已获客户授权、可否公开或匿名 |
| 品牌故事 | 品牌起源、发展关键节点、研发与产品迭代、经营理念、专注做什么、明确不做什么 |
| 创始人与社会贡献 | 创始人/负责人姓名职务与可公开履历、公益项目、本地就业、行业培训或产业贡献、可公开的事件与时间 |
| 竞品与混淆主体 | 主要竞争对手、希望规避的同名/近名公司、不愿被 AI 混淆的主体 |
| 目标与内容红线 | 希望 AI 推荐哪个核心业务、主推哪类客户、哪些客户/数据/价格/流程不能公开、对外内容由谁审核 |
| 资料文件 | 企业介绍、产品资料、案例、资质、评价、Logo、图片、视频、docx、xlsx、pdf、网页链接的清单 |

## 给用户的引导语

“我已学习完 GEO V3 仓库并完成框架分析。请提交客户资料，或告诉我是否需要《客户资料填写表》：需要的话我先生成表格，你按表逐项填；不需要的话，直接把企业介绍、产品资料、案例或链接发给我，缺的内容我会标为 MISSING 再统一向你确认。”
