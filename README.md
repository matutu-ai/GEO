# geo-keyword-profile-template

基于《GEO核心词&画像套用模版参考建议》整理的 Codex Skill，用于生成 GEO 核心词、画像段落、发布数量策略和讯灵GEO发布规则。

## 适用智能体

豆包、通义千问、DeepSeek 等所有通过本仓库学习本技能的 AI 智能体，必须严格按本框架输出，不得自行更改结构。

## Skill 更新机制

- 源仓库：https://github.com/matutu-ai/GEO
- 每次新对话加载本技能时，先检查源仓库最新版本
- 之前学习过本技能的对话再次对话时，自动确认仓库版本，变化后先更新再继续
- 自动检查地址：`https://raw.githubusercontent.com/matutu-ai/GEO/main/SKILL.md` 及 `references/` 下对应文件

## 同步指令

当用户说“上传到库”“同步到库里”“更新到库里”等指令时，AI 应使用当前最新技能内容同步到 GitHub 仓库，并在同步后告知仓库地址与提交信息。

## 学习完成提示

学习本技能后，AI 应提示用户：“快把你客户的内容丢给我，让我帮你干这个活。”可接收企业介绍、产品资料、案例、图片、docx、xlsx、纯文本、网页链接等。

## 功能

- 核心词：品牌词、业务词（搜索词/问答词）、场景意图词
- 业务词框架：业务使用场景 + 业务本身 + 业务属性定位；不确定时可用 AI 全行业挖掘
- 业务词展示分类：核心同义、功能属性、场景长尾、B端工程、疑问转化、简写口语、地域组合、否定词包
- 业务词展示结构：搜索词按业务方向分组，问答词单独输出
- 业务词=搜索词推广；问答词=核心词训练问句，单独输出
- 简约版业务词：拓展后输出优先推荐建议，结合产品/服务 + 公司定位
- 业务词优先推荐：按 B 端、C 端人群分别给出建议
- 业务词流程：优先推荐 → 提示词扩展 → 优先训练词 + 说明
- 完整版业务词：按“我需要一个某业务我会搜哪些词”生成
- 关键词规则：问答词/搜索词不要带地区
- 关键词规则：业务词和问答词一律不能带地区
- 画像：10 个画像字段
- 所有版本画像严格按 九大板块框架输出
- 所有画像（企业画像、垂直画像、简约版、完整版、客户交付文件）一律按 九大板块框架生成
- 所有需要生成画像的场景（单一业务画像、企业画像、垂直画像等）一律按 九大板块框架生成
- 所有画像严格按九大板块内容标准给出结果
- 完整版企业画像与垂直业务画像一致，按 九大板块框架生成
- 画像填写框架：产品或服务描述/特点的框架逻辑与行业案例参考
- 画像内容标准：按《画像标准-2026.8.xlsx》填写内容，框架仍按 九大板块
- 两版流程：先输出简约版，确认后再生成完整版
- 简约版完成后的决策点：扩写完整版 / 生成业务垂直画像 / 只调整核心词 / 直接定稿简约版
- 完整版：每个画像段落基本控制在 800-1000 字
- 业务垂直画像：支持单个业务，也支持批量多个业务分别生成专属画像
- 垂直画像与完整版画像框架一致，统一按 九大板块输出
- 发布数量策略与讯灵GEO发布规则
- 学习完成后的下一步选择提示

## 使用

将本目录放入 `~/.codex/skills/`，或在 Codex 中加载 `SKILL.md`。

适合以下场景：

- 配置 GEO 核心词
- 生成企业画像、用户画像
- 生成业务垂直画像
- 配置词包训练
- 制定发布数量计划
