# Search Intent Engine 搜索意图

## 意图类型

- Informational
- Commercial
- Transactional
- Navigational
- Comparison
- Problem-solving
- Procurement
- Local
- Technical

## 示例

- “某业务是什么” → Informational
- “某业务厂家” → Commercial / Procurement
- “某业务怎么选” → Commercial / Problem-solving
- “A和B有什么区别” → Comparison
- “某业务价格” → Transactional
- “本地某业务” → Local

## 规则

- 每个关键词必须关联意图
- 一个关键词可以关联多个意图
