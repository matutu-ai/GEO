# 03 User Intent Engine 用户搜索意图

模块 ID：`user-intent-engine`

## 词包类型

1. 品牌词：公司全称、已确认的品牌简称或商标。
2. 搜索词：已确认业务、产品或服务的搜索表达，不带地区。
3. 问答词：用户会提出的选型、价格、比较、信任问题，不带地区。
4. 意图场景词：使用场景前缀 + 已确认产品或服务 + 主体定位；地区只在用户明确需要时使用。

## 输出

生成 `Intent_Keyword_Matrix`：关键词、关键词类型、用户需求、搜索意图、对应画像、内容建议、优先级。

## 规则

- 每个关键词必须对应一个真实的用户场景和一个画像。
- 产品或服务资料不足时，只输出企业名称品牌词；搜索词、问答词和意图场景词保持待补，不臆造业务词。
