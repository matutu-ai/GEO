# 05 EEAT Trust Engine

模块 ID：`trust-engine`

## 输出

`Trust_Report` 包含 Expertise、Experience、Authority、Trustworthiness 四项各 25 分，以及总分、缺失和优化建议。

## 评分依据

- Expertise：明确的产品、能力、技术资料。
- Experience：可公开核验的项目与案例资料。
- Authority：资质、认证、专利、媒体与行业证明。
- Trustworthiness：官网、企业主体、业务边界和来源一致性。

评分表示当前资料完整度，不代表企业实际实力或第三方信用评级。
