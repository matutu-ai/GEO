# Intake 企业资料接收

## 输入

- 企业资料文件或文本
- 可包含：企业介绍、产品、案例、资质、评价、图片、链接
- 用户投喂本仓库后的框架分析与客户资料收集指令

## 步骤

1. 用户投喂本仓库时，先输出仓库框架分析摘要，不直接开始生成。
2. 框架分析完成后，提示用户提供客户资料，并询问是否需要《客户资料填写表》。
3. 用户需要表格时，按 `templates/client-intake-table.md` 输出 Markdown 填写表，让用户逐项补充。
4. 用户提交资料后，识别资料类型：docx / xlsx / 纯文本 / 网页链接 / 图片。
5. 提取原始内容，不修改原文语义。
6. 识别企业主体：公司名称、品牌、行业、产品、客户、地区。
7. 标记不确定信息。
8. 判断资料完整度。
9. 输出 `missing_information`。
10. 把已确认事实、待验证事实和缺失信息写入客户语料库的事实与证据库，供后续训练和优化使用。

规则：用户不需要表格或直接给资料时，不强制等待表格；表格只为提高资料完整度，缺项仍按 MISSING 处理，不虚构内容。语料库创建由生成简约版时自动触发，这里只先完成事实登记。

## 输出

- 原始资料摘要
- 已确认事实
- 待验证事实
- 缺失信息
- 风险标记
- 是否已提供《客户资料填写表》及待补项
- 已登记到客户语料库的事实与证据条目
