# Fast Path 快速执行协议

适用：用户只需要 GEO 场景词库、九大画像和优化方案，或在豆包、千问、DeepSeek 等平台需要减少投喂量时。

## 一次执行

1. 只接收一份资料包：公司名称、官网、定位、主营业务、产品、目标客户、区域、场景、业务边界和证据；用户意图为可选项。
2. 先把资料归一化为 `Fact_Packet`，区分 `provided`、`source_verified`、`unknown`；未知字段统一标记 `【需企业提供真实佐证】`。
3. 在同一次上下文中依次完成 Company_Profile、Product_Profile、Intent_Keyword_Matrix、Nine_Personas 和 Trust_Report。
4. 同时导出简约版词与画像、完整版四类词矩阵、完整版旧九大画像报告和 GEO 优化方案；不生成文章、内容正文或发布计划。
5. 输出一次缺失清单和一个下一步选择，不重复复述全部输入资料。

## 平台投喂规则

- 有目录读取能力：先读 `SKILL.md`、`INDEX.md`，再只读本文件和任务所需 Schema。
- 无目录读取能力：一次投喂 `SKILL.md`、`INDEX.md`、本文件和资料包；不要逐份投喂无关模板、旧工作流或全部参考资料。
- 需要内容建设时，再读取 `workflows/07_content_strategy.md`；需要旧版发布、验证或 Gap 模块时，用户点名后再读取。
- 外部检索不是默认步骤。用户明确要求检索时，记录来源和抓取时间，并将外部事实与企业自述分开。

## 结束提示

完成默认产物后只提示一个问题：`是否确认简约版方向，补充缺失资料，或明确指定下一项任务？`
用户补充资料后，先询问是否更新客户语料库；未确认时只在当前任务上下文中使用，不创建或回写语料库。
