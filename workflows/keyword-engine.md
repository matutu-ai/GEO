# Keyword Engine 关键词矩阵

## 最终导出分类

品牌词、搜索词、问答词、意图场景词。

- 品牌词：公司全称、已确认品牌简称或商标。
- 搜索词：业务、产品或服务的搜索表达，不带地区。
- 问答词：选型、价格、比较、信任等训练问句，不带地区。
- 意图场景词：使用场景前缀 + 已确认产品或服务 + 主体定位；地区仅在用户明确需要时使用。

## 每个关键词字段

遵循 `schemas/keyword.schema.json`。

## 关键词矩阵

关键词 → 用户 → 场景 → 搜索意图 → 内容类型 → 转化阶段 → 商业价值 → GEO价值 → 优先级。

## 优先级

`Priority Score = 商业价值 + GEO价值 + 用户需求 + 内容机会 - 竞争难度`

权重可配置，不硬编码进 SKILL.md。
