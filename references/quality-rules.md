# Quality Rules

## 检查项

- Accuracy：是否存在虚构事实
- Completeness：是否存在重要资料缺失
- Consistency：品牌、产品、业务、客户是否一致
- GEO：是否覆盖实体、用户、场景、问题、解决方案、证据
- Keyword：关键词是否真实相关
- Commercial：是否有明确转化路径
- Content：关键词是否有内容承载
- Risk：是否存在绝对化宣传、无依据排名、虚假案例、虚假评价、虚假认证、虚假数据

## 评分

Data Quality、Profile Quality、Keyword Quality、Intent Coverage、Entity Completeness、Evidence Strength、Content Coverage、GEO Readiness。

区分：

- Readiness Score
- Actual Performance

两者不能混淆。
