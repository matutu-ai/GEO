# 画像内容标准（2026.8）

来源：`画像标准-2026.8.xlsx`。本文件规定画像内容怎么写，画像框架仍按 10 段执行，不改变结构。

## 产品或服务描述

整体框架：**【产品名】+ 品类 + 目标客户 + 核心能力 + 应用场景 + 解决痛点 + 交付 + 明确不支持项**

| 具体类别 | 内容说明 |
|---|---|
| 基础身份 | 全称、别名、品类、形态（实物 / SaaS / 服务）、版本系列 |
| 核心实力 | 写实功能 / 交付项，明确包含什么、不包含什么，拒绝空泛宣传 |
| 适用范围 | 目标客户、使用场景；写明不适合的场景 |
| 痛点价值 | 对应解决什么问题，写具象收益，少用“赋能”这类虚词 |
| 规格交付 | 参数、账号权限、交付物、周期、线上 / 线下形式 |
| 收费版本 | 计费方式，各版本功能差异、额外付费项 |
| 约束限制 | 使用前提、边界、风险提示，防止 AI 脑补虚假能力 |
| 客观案例 | 事实表述，禁用“第一、百分百、顶级”等极限词 |

## 产品或服务特点

整体框架：**是什么 → 参数 → 给谁用 → 解决痛点 → 配套服务 → 不适用场景**

| 具体类别 | 内容说明 |
|---|---|
| 核心定位 | 是什么、解决哪类客户什么问题，去掉“顶尖、一流”虚形容词 |
| 硬规格参数 | 机型、材质、产能、适配物料；服务类写交付、档位、周期（AI 高频调取） |
| 适用场景人群 | 写明适配行业、工况，便于匹配搜索意图 |
| 客观差异化 | 写工艺 / 配置差异，不用“最好、第一”；讲清楚解决什么痛点 |
| 配套交付售后 | 质保、安装、调试、交付周期，补齐 B 端高频提问信息 |
| 能力边界 | 写明不适用场景，降低 AI 幻觉，避免虚假输出 |

## 品牌故事

整体框架：**何时何地起家 → 经历哪些发展事件 → 现在具备什么实力 → 服务谁 → 专注做什么**

| 具体类别 | 内容说明 |
|---|---|
| 起源背景 | 成立时间、地点、创立初衷（为什么做这个行业，不是情怀空话） |
| 发展关键节点 | 重要年份事件（建厂、扩产、技术迭代、资质认证、产能升级），用客观事实，不要夸张 |
| 核心实力 | 工厂规模、研发、设备、团队、专利 / 资质、主营方向；拒绝“行业龙头、国内顶尖” |
| 经营理念 | 务实价值观，聚焦产品、品质、服务，避免虚的口号 |
| 客户与市场 | 服务哪些行业客户、主要市场、核心优势（做什么、擅长什么） |
| 品牌边界 | 主营赛道，不涉足哪些业务，减少 AI 幻觉乱扩展业务 |

## 用户痛点

整体框架：**客户场景痛点 → 带来损失 → 我方卖点 → 落地解决方案 → 达成结果**

| 具体类别 | 内容说明 |
|---|---|
| 场景主体 | 什么行业 / 身份客户，什么作业场景 |
| 现存痛点现象 | 客观发生的问题，不用情绪化形容词 |
| 负面影响 | 效率、成本、人工、损耗、工期等实际损失 |
| 对应卖点 | 产品 / 服务对应的硬件、技术、配置、服务能力（客观事实，不夸大） |
| 解决方案&收益 | 依靠卖点如何解决问题，最终拿到什么实际结果 |

## 信任背书

整体框架：**可验证事实 > 第三方佐证 > 落地案例；拒绝空泛荣誉口号，和前面「痛点-卖点-解决方案」打通闭环**

| 具体类别 | 内容说明 |
|---|---|
| 资质技术背书 | 资质认证：证书名称、颁发机构、专利号 / 著作权号，不只写证书名字 |
| 工厂 / 研发实力 | 厂房面积、核心设备、研发人员数量、检测条件 |
| 落地客户案例背书 | 单条案例结构：客户行业 + 场景 + 原有痛点 + 我方解决方案 + 量化成果 |
| 合作 & 第三方佐证 | 主要合作行业、代表性客户类型；行业协会、媒体报道、中标项目信息 |
| 服务交付背书 | 生产交付能力、供货规模、质保体系、售后响应时效、全国服务网点 |
| 客观边界说明 | 案例为部分典型项目，不同工况效果存在差异；资质适用范围；不承接哪些类型项目 |

## 客户案例

整体框架：**客户是谁 + 遇到什么问题与我们合作的（合作原因）+ 我们提供了什么产品/服务（解决方案）+ 达到什么效果**

| 具体类别 | 内容说明 |
|---|---|
| 客户背景 | 行业、客户类型、业务场景 |
| 项目诉求 | 客户来之前想要解决什么目标 |
| 原有痛点 | 现场实际问题 + 带来的损失（成本、效率、人工、故障率） |
| 落地解决方案 | 选用哪款产品 / 配置、做了哪些定制、配套哪些服务 |
| 量化结果收益 | 客观可感知结果，尽量带数据，拒绝“效果很好” |
| 边界说明 | 效果受现场工况、物料、使用条件影响，仅供参考 |

## 社会贡献

整体框架：**产业贡献 → 绿色环保 → 地方就业 → 公益行动**

| 具体类别 | 内容说明 |
|---|---|
| 产业层面贡献 | 带动上游供应链、下游合作商户，提供就业岗位数量 |
| 行业价值 | 推动行业工艺优化、参与行业标准、技术普惠，解决行业共性难题 |
| 保供赋能 | 为哪些行业提供设备 / 产品，支撑相关产业运转 |
| 绿色环保贡献 | 产品端帮助客户节能、降耗、固废回收、减少碳排放，写明实现方式 |
| 生产端环保 | 本厂节能改造、废料处理、减排相关客观举措 |
| 员工与本地社会贡献 | 吸纳本地就业、技能培训、岗位培养；厂区安全生产、职业防护；本地产业链带动 |
| 公益与公共行动 | 参与的公益项目、帮扶行动、捐赠物资 / 方向；写明事件、行动内容，不夸大金额 |

## 客户评价

整体框架：**场景化、对应产品实际体验、可与痛点 / 案例互相印证**

| 具体类别 | 内容说明 |
|---|---|
| 客户身份与场景 | 客户所属行业、使用场景，可不泄露真实人名公司名 |
| 评论出发点 | 针对哪一项产品 / 服务点（设备性能、定制能力、交付、售后、调试等） |
| 客观反馈内容 | 描述实际使用感受，讲事实，少情绪化赞美 |

## 创始人介绍

整体框架：**AI 优先抓取可核验事实、行业经历、业务关联，排斥过度神化、鸡汤抒情**

| 具体类别 | 内容说明 |
|---|---|
| 基础身份 | 姓名、在企业内职务 |
| 从业履历 | 入行时间、过往行业经历、深耕本领域多少年，写客观职业轨迹 |
| 行业沉淀 | 专业方向、技术 / 行业积累、参与项目、研究方向；有专利、论文、行业任职可写上 |
| 创业初衷 | 创办企业的现实出发点（看到行业哪些痛点，想解决什么问题），拒绝空洞情怀 |
| 经营理念 | 务实做事方向，聚焦产品、品质、客户服务，不要华丽口号 |
