# 九大画像字段参考

仅在编写完整版或垂直完整版时按需查阅。字段是整理线索，不是必须填满的清单；只使用企业确认且允许用于本次交付的资料。对外使用还需确认授权。

| 板块 | 可整理的事实维度 |
| --- | --- |
| 产品或服务描述 | 名称与品类、目标客户、核心能力、场景、解决的问题、交付内容与边界 |
| 产品或服务特点 | 定位、已证实功能/参数、适用场景、客观差异、配套服务、不适用范围 |
| 品牌故事 | 起源、重要发展节点、品牌与企业主体关系、经营理念、主营方向 |
| 用户痛点 | 用户类型、实际场景、遇到的问题、决策顾虑、业务如何回应 |
| 信任背书 | 可核验资质、认证、团队、合作、官方渠道及服务交付依据 |
| 客户案例 | 客户背景、需求、方案、过程、可公开结果与适用边界 |
| 社会贡献 | 有来源的行业、就业、环保、本地或公益行动 |
| 客户评价 | 获授权的真实评价、客户场景、反馈内容和来源 |
| 创始人介绍 | 已确认身份、职务、专业经历、创业背景及其与业务的关系 |

完整版按九项分别成段，每段目标 800–1000 个中文字；简约版各项只写主体与核心事实。资料不足时标注待补，不能用行业常识、推断、重复表述或虚构案例来凑字数。
