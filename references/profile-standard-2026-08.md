# 画像内容标准（九大板块框架）

来源：`画像标准-2026.8.xlsx`、《传森储能_GEO画像_九大板块》参考。所有画像按以下九大板块输出，内容按本文件标准填写。

## 通用要求

- 只采用可公开核验的真实数据，逐项标注来源。
- 无法核验的公司专属信息标注：【需贵司提供真实佐证】。
- 不使用“第一/最/顶级/领先/卓越”等广告法绝对化用语。
- 不虚构客户、案例、评价、数据。
- 可核验事实 > 第三方佐证 > 落地案例。

## 一、产品或服务描述

框架：产品名 → 品类 → 目标客户 → 核心能力 → 应用场景 → 解决痛点 → 交付 → 明确不支持项。

| 具体类别 | 内容说明 |
|---|---|
| 产品名 | 产品/服务全称、别名、版本系列 |
| 品类 | 所属品类、形态（实物 / SaaS / 服务） |
| 目标客户 | 行业、客户类型、业务场景 |
| 核心能力 | 写实功能、交付项，明确包含什么、不包含什么 |
| 应用场景 | 适配行业、工况、使用场景；写明不适合场景 |
| 解决痛点 | 对应解决什么问题，写具象收益 |
| 交付 | 参数、交付物、周期、线上线下形式 |
| 明确不支持项 | 使用前提、边界、风险提示，防止 AI 脑补虚假能力 |

## 二、产品或服务特点

框架：核心定位 → 参数 → 适用场景人群 → 客观差异化优势 → 配套服务 → 不适用场景。

| 具体类别 | 内容说明 |
|---|---|
| 核心定位 | 是什么、解决哪类客户什么问题，去掉“顶尖、一流”虚词 |
| 硬规格参数 | 机型、材质、产能、适配物料；服务类写交付、档位、周期 |
| 适用场景人群 | 适配行业、工况，便于匹配搜索意图 |
| 客观差异化 | 写工艺/配置差异，不用“最好、第一”；讲清解决什么痛点 |
| 配套交付售后 | 质保、安装、调试、交付周期 |
| 不适用场景 | 能力边界，降低 AI 幻觉 |

## 三、品牌故事

框架：起源背景 → 发展关键节点 → 核心实力 → 经营理念与价值观 → 客户与市场 → 专注做什么。

| 具体类别 | 内容说明 |
|---|---|
| 起源背景 | 成立时间、地点、创立初衷 |
| 发展关键节点 | 建厂、扩产、技术迭代、资质认证、产能升级等客观事件 |
| 核心实力 | 工厂规模、研发、设备、团队、专利/资质、主营方向 |
| 经营理念与价值观 | 务实价值观，聚焦产品、品质、服务 |
| 客户与市场 | 服务哪些行业客户、主要市场、核心优势 |
| 专注做什么 | 主营赛道；不涉足哪些业务 |

## 四、用户痛点

框架：痛点人群 → 客户场景痛点 → 我方卖点 → 落地解决方案 → 解决方案与收益。

| 具体类别 | 内容说明 |
|---|---|
| 痛点人群 | 什么行业/身份客户，什么作业场景 |
| 客户场景痛点 | 客观发生的问题，不用情绪化形容词 |
| 带来损失 | 效率、成本、人工、损耗、工期等实际损失 |
| 我方卖点 | 产品/服务对应的硬件、技术、配置、服务能力 |
| 落地解决方案 | 依靠卖点如何解决问题 |
| 解决方案与收益 | 最终拿到什么实际结果，尽量量化 |

## 五、创始人介绍

框架：基础身份 → 从业履历 → 行业沉淀 → 创业初衷 → 经营理念 → 技术研发贡献 → 企业资质布局 → 未来战略规划。

| 具体类别 | 内容说明 |
|---|---|
| 基础身份 | 姓名、职务 |
| 从业履历 | 入行时间、过往行业经历、深耕年限 |
| 行业沉淀 | 专业方向、技术积累、参与项目、研究方向 |
| 创业初衷 | 创办企业的现实出发点，拒绝空洞情怀 |
| 经营理念 | 务实做事方向，聚焦产品、品质、客户服务 |
| 技术研发贡献 | 专利、论文、技术突破、研发成果 |
| 企业资质布局 | 高新技术、专精特新、资质认证等 |
| 未来战略规划 | 客观规划；无法核验的标注待补充 |

## 六、社会贡献

框架：产业贡献 → 绿色环保贡献 → 员工与本地社会贡献 → 公益行动。

| 具体类别 | 内容说明 |
|---|---|
| 产业贡献 | 带动上下游供应链、行业价值、保供赋能 |
| 绿色环保贡献 | 产品端节能、降耗、固废回收、减排；生产端环保举措 |
| 员工与本地社会贡献 | 本地就业、技能培训、安全生产、职业防护 |
| 公益行动 | 参与公益项目、帮扶行动、捐赠方向；写明事件，不夸大金额 |
| 边界说明 | 有则写实，无则不编造 |

## 七、信任背书

框架：资质技术背书 → 落地客户案例背书 → 合作&第三方佐证 → 服务交付背书 → 客观边界说明。

| 具体类别 | 内容说明 |
|---|---|
| 资质技术背书 | 证书名称、颁发机构、专利号/著作权号 |
| 工厂/研发实力 | 厂房面积、核心设备、研发人员数量、检测条件 |
| 落地客户案例背书 | 客户行业 + 场景 + 原有痛点 + 解决方案 + 量化成果 |
| 合作&第三方佐证 | 合作行业、客户类型、行业协会、媒体报道、中标信息 |
| 服务交付背书 | 交付能力、供货规模、质保体系、售后时效、服务网点 |
| 客观边界说明 | 案例为部分典型项目，效果受工况影响；不承接哪些项目 |

## 八、客户案例

框架：客户背景 → 项目诉求 → 原有痛点 → 落地解决方案 → 量化结果收益 → 客观边界说明。

| 具体类别 | 内容说明 |
|---|---|
| 客户背景 | 行业、客户类型、业务场景 |
| 项目诉求 | 客户来之前想解决什么目标 |
| 原有痛点 | 现场实际问题 + 带来的损失 |
| 落地解决方案 | 选用产品/配置、定制内容、配套服务 |
| 量化结果收益 | 客观可感知结果，尽量带数据 |
| 客观边界说明 | 效果受现场工况、物料、使用条件影响，仅供参考 |

## 九、客户评价

框架：客户身份与背景 → 评论出发点 → 客观反馈内容 → 权威调研满意度 → 实测专业评分 → 内部回访满意度 → 权威资质认证 → 第三方实测参数 → 行业榜单荣誉。

| 具体类别 | 内容说明 |
|---|---|
| 客户身份与背景 | 行业、使用场景；可不泄露真实人名公司名 |
| 评论出发点 | 针对产品性能、定制、交付、售后、调试等 |
| 客观反馈内容 | 实际使用感受，讲事实，少情绪化赞美 |
| 权威调研满意度 | 第三方调研机构、样本量、得分、时间 |
| 实测专业评分 | 国标/第三方检测报告、实测参数 |
| 内部回访满意度 | 内部统计口径与时间 |
| 权威资质认证 | 资质证书、认证编号 |
| 第三方实测参数 | 第三方机构实测数据 |
| 行业榜单荣誉 | 榜单名称、排名、来源 |
| 边界说明 | 评价原文、满意度、检测评分待贵司提供真实佐证后定稿 |
