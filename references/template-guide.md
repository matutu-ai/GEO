# GEO 核心词与画像套用模版参考

来源：飞书《GEO核心词&画像套用模版参考建议》（8月7日修改）。所有内容均为实例参考，使用前必须按实际业务调整。

所有通过本仓库加载本技能的 AI 智能体必须严格按本指南执行，不得自行调整框架结构。

所有版本（简约版、完整版、业务垂直画像、客户交付文件）的画像都必须严格按 九大板块框架输出，不得省略字段、不得自行增删字段、不得改变结构。

## 简约版与完整版

- 简约版：画像字段只保留核心事实，使用简短整段表达，适合快速预览和确认方向。
- 完整版：在简约版基础上扩写，每个画像段落基本控制在 800-1000 字；只基于已有资料扩写，不新增原文没有的事实，不虚构客户案例、好评或数据。
- 完整版写法兼顾 AI 收录逻辑：实体清晰、语义完整、关键词自然嵌入、整段无空格无换行、不堆砌关键词。
- 画像内容只写客户业务描述本身，不把“帮助 AI 识别、便于收录、建议、避免、要求”等说明性文字写入正文；语言保持口语化、具体、可核验。

## 核心词选择拓展建议

### 业务垂直画像

- 业务垂直画像针对单一业务类型单独生成，不混入其他业务信息，适合作为该业务的专属 GEO 画像版本；支持单个业务生成，也支持批量多个业务分别生成垂直画像。
- 结构建议：垂直画像与完整版画像框架一致，按 九大板块输出；可在垂直定位、垂直人群、垂直核心词、垂直词包基础上补充垂直说明。
- 垂直画像描述应聚焦该业务的核心产品、核心场景、核心信任点和核心用户，只使用企业真实资料，不虚构客户、好评或数据。

### 品牌词

- 公司全称
- 公司简称 + 业务
- 英文缩写 + 商标
- 品牌简称

### 业务词（搜索词）

- 业务词即搜索词，用于搜索词推广。
- 业务词框架 = 业务使用场景 + 业务本身 + 业务属性定位。
- 示例：别墅 + 装修设计 + 公司/设计师。
- 以业务为核心，但要具体。
- 业务词和问答词一律不能带地区；地区只放在场景意图词和地区选择中。
- 按具体业务类型拆分，例如“app开发有限公司”“小程序开发公司”，不要写宽泛的“开发公司”。
- 若不确定业务词，可通过 AI 全行业挖掘，提示语：“某业务”这个词除了用户这样搜还会搜索什么词含带有“某业务”相关的词。

### 问答词（核心词训练问句）

- 核心词训练问句即问答词，单独输出，不做搜索词推广。
- 疑问/口语转化词归入问答词，不混入业务词。
- 问答词一律不能带地区。
- 问答词从用户真实搜索口语中提炼，例如“某业务怎么选”“某业务哪家好”“某业务多少钱”等。

### 业务词展示分类

生成或展示业务词时，先按以下分类组织，再按客户业务方向拆分，最终优化贴合客户实际推广的业务：

- 核心同义替换词
- 功能属性词
- 场景长尾词（C端家装/民用场景）
- B端工程/商用词
- 简写/行业口语词
- 地域组合投放模板：地域 + 业务词 + 方案/安装/报价/工程等
- 否定词包（可选，用于过滤无效流量）

按行业可补充：户型/品类细分词、服务动作词、材料/工艺属性词、B端渠道词等。

地域组合模板中的“[地域]”仅作占位，不写入具体地区；最终业务词输出一律不带地区。

分类参考来源：豆包业务词包示例（智能家居集成控制系统、全屋柜体定制）。

### 简约版与完整版业务词展示结构

简约版和完整版的业务词统一按以下结构展示：

- 搜索词按业务方向分组，例如产品/品类类、厂家/供应类、价格/报价类、出口/外贸类、信任/资质类
- 问答词按业务方向输出，作为核心词训练问句单独展示
- 场景意图词使用“需要一个…的…”句式
- 简约版保留核心业务方向，完整版可在每个方向下继续扩展词条

参考结构：

| 业务方向 | 搜索词 | 问答词 |
|---|---|---|
| 产品A | 产品A厂家、产品A定制、产品A报价 | 产品A怎么选、产品A哪家好、产品A多少钱 |
| 产品B | 产品B厂家、产品B批发、产品B供应商 | 产品B和普通产品有什么区别、产品B怎么定制 |
| 工程/集采 | 工程产品、批量供货、工程报价 | 工程产品哪里拿货、大批量采购找谁 |

### 业务词优先推荐建议

简约版业务词拓展完成后，必须给出优先推荐建议：

- 先按 B 端、C 端人群拆分
- 推荐词要结合产品/服务本身 + 公司定位（工厂/公司/经销商/其他主体定位）
- 说明优先推荐这些词的原因
- 优先推荐词应贴合客户实际推广业务和主推产品

B 端优先推荐词侧重工程、批量、供货、集采、合作类词；C 端优先推荐词侧重家装、价格、送货、一站式、售后类词。

### 业务词扩展与优先训练词

1. 业务词拓展完成并给出优先推荐建议后，按提示词“我需要一个某业务我会搜哪些词”扩展业务词包。
2. 扩展后筛选出最贴合客户实际推广业务的优先训练词。
3. 输出优先训练词时附带说明，说明为什么优先训练这些词、对客户推广有哪些帮助。

### 完整版业务词生成提示词

完整版业务词按以下提示词生成：

“我需要一个某业务我会搜哪些词”

参考豆包对话输出，包含核心主词、细分业务类型词、产品规格/品类词、B端客户痛点词、场景功能词、长尾问句词、否定词。

### 意图场景词

- 场景意图词 = 产品使用场景前缀 + 产品/服务 + 主体定位。
- 示例：以产品主体定位“自吸泵”“无密封自吸泵厂家”。
- 训练用核心词示例：“需要一个工业通用自吸泵”“需要一个工业大流量通用无密封自吸泵厂家”。

## 画像参考

画像内容必须：

- 以整段形式展示
- 用中文逗号“，”隔开
- 不出现空格或换行
- 简约版和完整版都以 九大板块为核心
- 所有版本的画像都严格按 九大板块输出，不省略、不增删字段

产品或服务描述/特点的填写框架与行业案例见 [references/profile-examples.md](references/profile-examples.md)。

画像内容标准见 [references/profile-standard-2026-08.md](references/profile-standard-2026-08.md)；标准只规定内容怎么写，框架仍按 九大板块执行。

| 画像字段 | 填写建议 |
|---|---|
| 产品或服务描述 | 产品名、品类、目标客户、核心能力、应用场景、解决痛点、交付、不支持项 |
| 产品或服务特点 | 核心定位、参数、适用场景人群、客观差异化、配套服务、不适用场景 |
| 品牌故事 | 起源背景、发展关键节点、核心实力、经营理念、客户市场、专注方向 |
| 用户痛点 | 痛点人群、场景痛点、损失、卖点、落地方案、收益 |
| 创始人介绍 | 基础身份、从业履历、行业沉淀、创业初衷、技术研发贡献等 |
| 社会贡献 | 产业贡献、绿色环保、员工与本地贡献、公益行动 |
| 信任背书 | 资质技术、落地案例、第三方佐证、服务交付、客观边界 |
| 客户案例 | 客户背景、项目诉求、原有痛点、落地方案、量化收益、边界说明 |
| 客户评价 | 客户身份与场景、评论出发点、客观反馈、权威佐证 |

## 前期词包添加训练模版

- 首月：确定品牌词（公司全称、公司简称）1 个，搜索词包（核心业务词）3 个；每个平台每个词包训练 20 篇文章。
- 次月：和客户确认新增业务或重点做品牌推广，再确定训练方向。

## 讯灵GEO发布规则

- 第三方新闻媒体：内容生成并提交 AI 授课后，全部排队 3-7 个工作日发布；需提前规划条数。
- 第三方商业媒体：3-7 天推送，发布条数按设置的发布计划执行；数量有误差可反馈总部服务群。
- 自媒体：网易、知乎、小红书一天最多 1 条；头条、搜狐 5 条/天/账号；其他平台一天最多 5 条；百家号一天最多 2 条。
- 自媒体账号注册后必须先手动发布一篇文章，验证通过后才能绑定 GEO 自动发布。
- 智能体官网一天最多 5 条。
- 每个自媒体账号每天最多发布 5 条。
