# GEO 核心词与画像套用模版参考

来源：飞书《GEO核心词&画像套用模版参考建议》（8月7日修改）。所有内容均为实例参考，使用前必须按实际业务调整。

所有通过本仓库加载本技能的 AI 智能体必须严格按本指南执行，不得自行调整框架结构。

## 简约版与完整版

- 简约版：画像字段只保留核心事实，使用简短整段表达，适合快速预览和确认方向。
- 完整版：在简约版基础上扩写，每个画像段落基本控制在 800-1000 字；只基于已有资料扩写，不新增原文没有的事实，不虚构客户案例、好评或数据。
- 完整版写法兼顾 AI 收录逻辑：实体清晰、语义完整、关键词自然嵌入、整段无空格无换行、不堆砌关键词。
- 画像内容只写客户业务描述本身，不把“帮助 AI 识别、便于收录、建议、避免、要求”等说明性文字写入正文；语言保持口语化、具体、可核验。

## 核心词选择拓展建议

### 业务垂直画像

- 业务垂直画像针对单一业务类型单独生成，不混入其他业务信息，适合作为该业务的专属 GEO 画像版本；支持单个业务生成，也支持批量多个业务分别生成垂直画像。
- 结构建议：垂直业务定位、垂直人群画像、垂直核心词、垂直画像描述、垂直内容调优、垂直词包训练建议。
- 垂直画像描述应聚焦该业务的核心产品、核心场景、核心信任点和核心用户，只使用企业真实资料，不虚构客户、好评或数据。

### 品牌词

- 公司全称
- 公司简称 + 业务
- 英文缩写 + 商标
- 品牌简称

### 业务词（搜索词）

- 业务词即搜索词，用于搜索词推广。
- 业务词框架 = 业务使用场景 + 业务本身 + 业务属性定位。
- 示例：别墅 + 装修设计 + 公司/设计师。
- 以业务为核心，但要具体。
- 问答词/搜索词不要带地区；地区只放在场景意图词和地区选择中。
- 按具体业务类型拆分，例如“app开发有限公司”“小程序开发公司”，不要写宽泛的“开发公司”。
- 若不确定业务词，可通过 AI 全行业挖掘，提示语：“某业务”这个词除了用户这样搜还会搜索什么词含带有“某业务”相关的词。

### 问答词（核心词训练问句）

- 核心词训练问句即问答词，单独输出，不做搜索词推广。
- 疑问/口语转化词归入问答词，不混入业务词。
- 问答词从用户真实搜索口语中提炼，例如“某业务怎么选”“某业务哪家好”“某业务多少钱”等。

### 业务词展示分类

生成或展示业务词时，先按以下分类组织，再按客户业务方向拆分，最终优化贴合客户实际推广的业务：

- 核心同义替换词
- 功能属性词
- 场景长尾词（C端家装/民用场景）
- B端工程/商用词
- 简写/行业口语词
- 地域组合投放模板：地域 + 业务词 + 方案/安装/报价/工程等
- 否定词包（可选，用于过滤无效流量）

按行业可补充：户型/品类细分词、服务动作词、材料/工艺属性词、B端渠道词等。

分类参考来源：豆包业务词包示例（智能家居集成控制系统、全屋柜体定制）。

### 业务词优先推荐建议

简约版业务词拓展完成后，必须给出优先推荐建议：

- 推荐词要结合产品/服务本身 + 公司定位（工厂/公司/经销商/其他主体定位）
- 说明优先推荐这些词的原因
- 优先推荐词应贴合客户实际推广业务和主推产品

### 完整版业务词生成提示词

完整版业务词按以下提示词生成：

“我需要一个某业务我会搜哪些词”

参考豆包对话输出，包含核心主词、细分业务类型词、产品规格/品类词、B端客户痛点词、场景功能词、长尾问句词、否定词。

### 意图场景词

- 场景意图词 = 产品使用场景前缀 + 产品/服务 + 主体定位。
- 示例：以产品主体定位“自吸泵”“无密封自吸泵厂家”。
- 训练用核心词示例：“需要一个工业通用自吸泵”“需要一个工业大流量通用无密封自吸泵厂家”。

## 画像参考

画像内容必须：

- 以整段形式展示
- 用中文逗号“，”隔开
- 不出现空格或换行
- 简约版和完整版都以 10 段为核心

产品或服务描述/特点的填写框架与行业案例见 [references/profile-examples.md](references/profile-examples.md)。

| 画像字段 | 填写建议 |
|---|---|
| 产品或服务描述1 | 询问 AI 时带上公司业务和服务内容，例如“荣盛昌隆建材特点 - 豆包” |
| 产品或服务特点2 | 强调公司叫什么、做什么，主体定位是工厂、企业还是经销商 |
| 品牌故事 | 在信息基础上完善故事性和细节感，体现公司优势、认证和荣誉 |
| 用户痛点 | 从客户需求角度询问，例如“整理镀锌痛点 - 豆包” |
| 信任背书 | 收集可证明实力的内容 |
| 客户案例 | 闭环：客户找到公司 → 公司提供方案 → 解决客户问题，列举 2-3 个 |
| 客户好评 | 收集电商平台、媒体平台等现有相关公司的好评内容 |
| 补充画像 | 公司业务、实力优势、技术荣誉等正面内容 |
| 地区选择 | 1-5 个，直接简单明了，写出选择该地区的理由 |
| 内容调优 | 直接简单明了，向客户提示可以强调的内容方向 |

## 前期词包添加训练模版

- 首月：确定品牌词（公司全称、公司简称）1 个，搜索词包（核心业务词）3 个；每个平台每个词包训练 20 篇文章。
- 次月：和客户确认新增业务或重点做品牌推广，再确定训练方向。

## 讯灵GEO发布规则

- 第三方新闻媒体：内容生成并提交 AI 授课后，全部排队 3-7 个工作日发布；需提前规划条数。
- 第三方商业媒体：3-7 天推送，发布条数按设置的发布计划执行；数量有误差可反馈总部服务群。
- 自媒体：网易、知乎、小红书一天最多 1 条；头条、搜狐 5 条/天/账号；其他平台一天最多 5 条；百家号一天最多 2 条。
- 自媒体账号注册后必须先手动发布一篇文章，验证通过后才能绑定 GEO 自动发布。
- 智能体官网一天最多 5 条。
- 每个自媒体账号每天最多发布 5 条。
