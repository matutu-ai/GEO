# 讯灵画像填写案例参考

来源：飞书《讯灵画像填写案例参考》（6月18日修改）。仅作画像填写参考，需按客户实际业务调整。

## 产品或服务描述填写框架

**内容参考框架逻辑**：企业根基 → 硬性实力 → 核心业务 → 产能市场 → 全流程服务 → 精度标准 → 客群定位 → 应用场景 → 核心行业价值。

由浅入深：先定企业身份资质，再讲生产体量，接着讲加工服务体系、工艺标准，最后锁定客户与行业价值。

参考要素：

1. 企业基础：成立时间、曾用名、实缴资本、三大权威企业资质
2. 主营赛道：特殊钢延压 + 热处理 + 表面处理一体化加工
3. 产能市场：年产能、年产值、调质材全国市场占比
4. 主营产品：模具钢 / 工具钢 / 轴承钢 / 高速钢等品类
5. 全流程闭环服务：从原料检验到售后技术全链路工序
6. 硬核工艺精度：尺寸公差、硬度波动、交付时效优势
7. 精准客群：高端制造头部企业 + 中小制造试样客户
8. 行业适配：八大高端制造领域 + 极端工况适配
9. 核心价值：解决高端制造特钢材料卡脖子难题

## 产品或服务特点填写框架

**内容参考框架逻辑**：硬核功能特点 → 合作体验特点 → 技术研发特点 → 场景适配特点 → 市场差异化优势 → 客户最终价值。

从产品本身 → 合作体验 → 技术壁垒 → 场景适配 → 同行差异 → 客户获益五层提炼成交卖点。

参考要素：

1. 功能特点：完整自主工艺链、产能稳定、性能对标进口
2. 体验特点：可视化管控、试样灵活、7×12小时技术响应、高准时交付
3. 技术特点：专利数量、自研核心工艺、技术空白突破、长期设备升级规划
4. 场景特点：全行业定制适配、兼顾大小订单、覆盖研发到量产
5. 差异化优势：本土早期行业先行者、双认证 + 福利企业、自主工艺、降本增效
6. 客户感知价值：降报废、提品质、减采购成本、缩短研发周期
