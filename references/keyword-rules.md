# Keyword Rules

## 分类

品牌词、产品词、服务词、功能词、场景词、用户词、痛点词、解决方案词、采购词、比较词、问答词、地域词、B2B工程词、行业词、长尾词。

## 意图

Informational、Commercial、Transactional、Navigational、Comparison、Problem-solving、Procurement、Local、Technical。

## 矩阵

关键词 → 用户 → 场景 → 搜索意图 → 内容类型 → 转化阶段 → 商业价值 → GEO价值 → 优先级。

## 优先级

`Priority Score = 商业价值 + GEO价值 + 用户需求 + 内容机会 - 竞争难度`

权重可配置。
