# 四类 GEO 关键词规则

只使用以下四类，不再拆成多套互相重叠的词类。每条推荐词应贴合企业已确认的业务、客户和目标；客户原词与系统建议词分开标记。

| 类型 | 生成框架 | 训练用途 |
| --- | --- | --- |
| 品牌词 | 品牌名称；品牌 + 业务 + 企业定位 | 训练品牌识别及品牌、业务、主体之间的稳定关联 |
| 搜索词 | 使用场景 + 业务 + 定位 | 匹配用户在具体场景中的业务检索 |
| 问答词 | 业务需求 + 对比 / 判断 / 选择问题 | 训练对比、判断、筛选和决策回答 |
| 意图场景词 | “需要一个……” + 使用场景 + 产品/服务业务 | 匹配明确需求场景与对应方案 |

## 生成与筛选

- 先按四类各给少量高相关建议，再补充客户明确提出的词；不把词根直接当作最终推荐。
- 搜索词必须同时体现使用场景、业务和企业定位；避免只有宽泛行业词。
- 问答词采用真实用户会问的自然问题，优先覆盖对比、判断、选择；不得虚构价格、效果或政策答案。
- 意图场景词使用自然需求句式，清楚呈现需要、场景和产品/服务。
- 关键词说明只保留“推荐词、训练用途、状态”；不重复添加内容矩阵、发布计划、平台验证或没有资料支持的搜索量/竞争度评分。
- 保留 `客户提出 / 系统推荐` 与 `已确认 / 待确认` 状态。推荐不等于客户批准。
