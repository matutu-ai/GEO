# 四类 GEO 关键词规则

只使用以下四类，不再拆成多套互相重叠的词类。企业已确认事实限定推荐边界；客户原词与系统建议词分开标记。分类看用户意图，不只看句式或是否带问号。

| 类型 | 生成框架 | 训练用途 |
| --- | --- | --- |
| 品牌词 | 品牌名称；品牌 + 业务 + 企业定位 | 训练品牌识别及品牌、业务、主体之间的稳定关联 |
| 搜索词 | 地区（可选） + 使用场景 + 业务 + 定位 | 匹配用户在具体场景中寻找哪类服务/供应方 |
| 问答词 | 业务/需求 + 对比、判断、选择或适配问题 | 训练比较、筛选和决策回答 |
| 意图场景词 | 明确动作/任务 + 使用场景 + 产品/服务业务 | 匹配用户已经提出的任务或需求与对应方案 |

## 内部选词依据

- 从已确认的主体、主营业务、定位、目标客户、使用场景、用户痛点中依次提炼品牌根、业务根、定位根、人群根、场景根、需求根；核心词根是业务根。每个根记录原始事实 ID、来源、状态和核心标记；同义表达合并，未经确认不自行截断或改写。
- 短词根通常 3–10 个字；品牌官方名称或已确认业务名不适合截短时保留原词。缺失类别标待补，不补造词根。
- 业务根、场景根、需求根不带地区；提取地区以客户明确提供的服务范围为准，不从模糊语句推断。
- 搜索词用场景根＋业务根＋定位根；问答词用需求根或业务根＋比较／判断／选择；意图场景词用明确需求＋场景根＋业务根。词根不单独作为最终推荐词。
- 最终推荐词仍需把短词根与已确认的业务、场景或品牌连接，扩展为用户可能输入的自然搜索或提问；“我需要”“怎么样”不能单独作为最终词。
- 客户原词保持原样；只有能直接从原词或确认资料得到短词根时才填写。词根、自然问法和客户事实都不代表实际搜索热度，也不保证 AI 推荐。

## 来源与意图边界

- 先以客户确认事实限定品牌、业务、定位、人群和场景；客户提供的搜索词/问法原样保留，不能为贴合模板而改写。
- 默认系统建议是依据确认资料生成的候选表达，不是搜索平台实测词。Standard 默认不执行外部搜索或抓词，也不宣称热度、排名或 AI 推荐概率。
- 只有用户明确要求外部词源研究时，才采集搜索联想、问答区或指定平台的真实表达；逐条保留原句、来源平台/页面和采集日期，并区分“平台观察词”与“系统建议词”。平台出现不代表适配客户，仍需经过事实匹配与客户确认。当前 Standard JSON 合同只记录客户提出/系统推荐，尚不承载平台来源字段；未升级合同前，平台观察结果不能伪装成现有 CLI 的可追溯字段。
- 搜索词回答“在这个场景里，我去哪里/找什么服务”；问答词回答“怎么比较、判断或选择”；意图场景词表达“我有这个具体任务/需求，需要这项业务”。同一表达只归入最贴近主要意图的一类，不重复凑类。
- 例：`跨境独立站 SEO优化服务商` 是场景下找服务的搜索词；`SEO优化服务商怎么选？` 是决策问答词；`我需要提升跨境独立站自然流量，想找 SEO优化服务` 是明确需求场景词。例句仅演示分类，不代表实测热度。

## 生成与筛选

- 先生成品牌词和搜索词作为首轮训练重点，再补问答词与意图场景词；合并客户明确提出的词并保留来源，不把词根直接当作最终推荐。
- 搜索词必须同时体现使用场景、业务和企业定位；避免只有宽泛行业词。
- 问答词采用贴近真实决策的自然问题句式，优先覆盖对比、判断、选择；未采集并记录来源时，不称为平台实测问法；不得虚构价格、效果或政策答案。
- 意图场景词用自然表达写清用户要完成的事情、所处场景及对应产品/服务；避免只把问答词加上“我需要”。
- 每类最多 12 条；客户原词优先保留，系统建议补足剩余名额。若客户原词超过 12 条，先集中请用户筛选，不静默丢弃。
- 每条推荐词标明组成词根、训练用途、来源与状态；关联不上时标待核对，不硬绑。词根不单独形成客户交付章节。不添加内容矩阵、发布计划、平台验证或没有资料支持的搜索量/竞争度评分。
- 搜索词、问答词默认不带地区；仅用户明确要求且地区已确认时，意图场景词可加入地区。含地区的客户搜索词/问答词保持原样标示，但不算作本轮推荐。
- 保留 `客户提出 / 系统推荐` 与 `已确认 / 待确认` 状态。推荐不等于客户批准。

## 每条词的内部字段

每条推荐词必须同时记录：短词根、四类词类型、意向等级、搜索角色、业务线、场景、地区、来源、确认状态、关联九大画像板块。高/中/低意向是独立标签，不替代四类词分类。

- 高意向：找供应商、采购、供货、集采、报价、项目、招标或明确“我需要”。
- 中意向：怎么选、是否适合、对比、推荐、方案调研。
- 低意向：品牌名、品类名和基础认知；只作品牌关联与内容铺垫。

建议整体训练组合为高意向 60%、中意向 30%、低意向 10%，不要求每篇文章机械凑比例。客户搜索词与 BD 背调词必须分开，企业工商查询、合作核验和案例背调词不得混入客户获客词包。
