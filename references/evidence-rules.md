# Evidence Rules

## 证据等级

- A：企业官方资料 / 官方网站 / 企业正式文件
- B：企业主动提供但尚未外部验证的信息
- C：公开网络可验证信息
- D：AI 根据已知信息做出的合理推断
- E：缺失 / 待企业确认

## 每条重要信息

记录 `claim`、`source`、`evidence_level`、`verified`、`notes`。

## 严格禁止

- 编造客户
- 编造案例
- 编造销量
- 编造资质
- 编造认证
- 编造用户评价
- 编造创始人经历
- 编造生产能力
- 编造市场排名
- 编造数据

## 资料不足

不填充虚假内容，必须进入 `missing_information`。
